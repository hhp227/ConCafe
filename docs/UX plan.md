# 🎀 ConCafe UI 구조 설계 문서

## 📱 1. 하단 탭 구조 (Bottom Navigation)
[홈]  [탐색]  [체크인]  [랭킹]  [마이]

---

# 1️⃣ 🏠 홈 (Home)

### 목적
- 앱 진입 시 첫 화면
- 관심 메이드 & 인기 정보 노출

### UI 구성
- 상단: 로고 + 알림 아이콘
- 🔥 이번 주 인기 메이드 (가로 스크롤 카드)
- 📍 근처 메이드카페 (지도 미리보기 또는 카드 리스트)
- 🎂 생일인 메이드
- 📢 카페 공지 (최근 3개)

---

# 2️⃣ 🔍 탐색 (Explore)

### 상단
- 검색바
- 지역 필터 (KR / JP / 도시)
- 정렬 (인기순 / 최신순 / 평점순)

### 내부 탭
[카페]   [메이드]

#### 📍 카페 카드
- 썸네일 이미지
- 카페 이름
- 평점 및 리뷰 수
- 지역

#### 🎀 메이드 카드
- 프로필 이미지
- 이름
- 소속 카페
- 팔로워 수

---

# 3️⃣ 📍 체크인

### 메인 화면
- 오늘 방문한 카페
- + 방문 추가 버튼
- 최근 방문 타임라인

### 체크인 플로우
1. 카페 선택
2. 날짜 선택
3. 위치 인증 (100m 반경)
4. 메모 작성
5. 등록

---

# 4️⃣ 🏆 랭킹

### 상단 탭
[메이드 랭킹]  [카페 랭킹]

### 필터
- 기간 선택 (주간 / 월간)
- 지역 선택

---

# 5️⃣ 👤 마이 페이지

### 상단
- 프로필 이미지
- 닉네임
- 레벨
- 총 방문 횟수

### 섹션
- 방문 기록
- 즐겨찾기 카페
- 팔로우한 메이드
- 획득 배지
- 설정

---

# 📍 카페 상세 화면

- 대표 이미지 슬라이더
- 카페 이름
- 평점
- 지역
- 즐겨찾기 버튼

### 탭
정보 | 메이드 | 메뉴 | 리뷰 | 공지

#### 정보 탭
- 주소
- 지도
- 설명
- 영업시간

#### 메이드 탭
- 소속 메이드 리스트
- 출근 여부 표시

#### 메뉴 탭
- 음식
- 음료
- 가격
- 이미지

#### 리뷰 탭
- 별점 평균
- 리뷰 리스트
- 방문 인증 배지 표시

---

# 🎀 메이드 상세 화면

- 프로필 이미지 슬라이드
- 이름
- 소속 카페
- 팔로우 버튼
- 팔로워 수
- 출근 캘린더 (주간 보기)
- 소개글
- 최근 방문 인증 수

---

# 🔔 알림 화면

- 출근 알림
- 생일 알림
- 카페 공지
- 팔로우 업데이트

---

# 🎨 UX 설계 방향

- 카드 기반 레이아웃
- 이미지 중심 UI
- 지도 + 기록 강조
- 서브컬쳐 감성 유지
