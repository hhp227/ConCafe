# 🎀 ConCafe UI 구조 설계 문서

## 📱 1. 하단 탭 구조 (Bottom Navigation)
[홈]  [탐색]  [체크인]  [랭킹]  [마이]

### 메인 네비게이션 노출 규칙
- 게스트 또는 일반 유저(`VISITOR`) 로그인 상태:
  - [홈] [탐색] [체크인] [랭킹] [마이]
- 캐스트(`CAST`) 로그인 상태:
  - [홈] [탐색] [팬관리] [랭킹] [마이]
- 카페 운영자(`CAFE_OWNER`) 로그인 상태:
  - [홈] [탐색] [카페관리] [랭킹] [마이]
- 관리자(`ADMIN`) 로그인 상태:
  - [홈] [탐색] [운영관리] [랭킹] [마이]

### 역할별 탭 치환 원칙
- 세 번째 메인 탭은 기본적으로 `체크인` 영역이다.
- 로그인한 사용자 역할이 `CAST`이면 `체크인` 탭 대신 `팬관리` 탭을 노출한다.
- 로그인한 사용자 역할이 `CAFE_OWNER`이면 `체크인` 탭 대신 `카페관리` 탭을 노출한다.
- 로그인한 사용자 역할이 `ADMIN`이면 `체크인` 탭 대신 `운영관리` 탭을 노출한다.
- 게스트와 일반 유저는 항상 `체크인` 탭을 사용한다.
- 한 계정에 여러 역할이 공존하는 경우 우선순위는 `ADMIN > CAFE_OWNER > CAST > VISITOR`로 적용한다.

# 1️⃣ 🏠 홈 (Home)

### 목적
- 앱 진입 시 첫 화면
- 관심 메이드 & 인기 정보 노출

### UI 구성
- 상단: 로고 + 알림 아이콘
- 🔥 이번 주 인기 메이드 (가로 스크롤 카드)
- 📍 근처 메이드카페 (지도 미리보기 또는 카드 리스트)
- 🎂 생일인 메이드
- 📢 카페 공지 (최근 3개)

---

# 2️⃣ 🔍 탐색 (Explore)

### 상단
- 검색바
- 지역 필터 (KR / JP / 도시)
- 정렬 (인기순 / 최신순 / 평점순)

### 내부 탭
[카페]   [메이드]

#### 📍 카페 카드
- 썸네일 이미지
- 카페 이름
- 평점 및 리뷰 수
- 지역

#### 🎀 메이드 카드
- 프로필 이미지
- 이름
- 소속 카페
- 팔로워 수

---

# 3️⃣ 📍 체크인

### 메인 화면
- 오늘 방문한 카페
- + 방문 추가 버튼
- 최근 방문 타임라인

### 체크인 플로우
1. 카페 선택
2. 날짜 선택
3. 위치 인증 (100m 반경)
4. 메모 작성
5. 등록

### 노출 대상
- 게스트
- 일반 유저(`VISITOR`)

---

# 3-1️⃣ 🎀 팬관리

### 목적
- 캐스트가 팬과의 접점을 관리하는 전용 탭

### 메인 화면
- 내 프로필 요약
- 팔로워 수
- 출근 일정 바로가기
- 팬 대상 공지/알림 관리

### 노출 대상
- 캐스트(`CAST`)

---

# 3-2️⃣ ☕ 카페관리

### 목적
- 카페 운영자가 카페 운영 데이터를 관리하는 전용 탭

### 메인 화면
- 내 카페 요약
- 공지/이벤트 관리
- 메뉴/굿즈 관리
- 캐스트/출근표 관리

### 노출 대상
- 카페 운영자(`CAFE_OWNER`)

---

# 3-3️⃣ 🛠 운영관리

### 목적
- 관리자가 승인/반려/운영 상태를 처리하는 전용 탭

### 메인 화면
- 카페 승인 대기 목록
- 운영자/캐스트 Claim 승인
- 신고/밴 관리
- 전체 운영 현황

### 노출 대상
- 관리자(`ADMIN`)

---

# 4️⃣ 🏆 랭킹

### 상단 탭
[메이드 랭킹]  [카페 랭킹]

### 필터
- 기간 선택 (주간 / 월간)
- 지역 선택

---

# 5️⃣ 👤 마이 페이지

### 상단
- 프로필 이미지
- 닉네임
- 레벨
- 총 방문 횟수

### 섹션
- 방문 기록
- 즐겨찾기 카페
- 팔로우한 메이드
- 획득 배지
- 설정

### 설정 화면
- 계정 관리
- 알림 설정
- 앱 버전 정보
- 로그아웃

메모:
- 현재 단계에서는 설정 데이터 저장 없이 화면만 추가한다.
- 마이 페이지에서 설정으로 진입하고 뒤로가면 마이 페이지로 복귀한다.
