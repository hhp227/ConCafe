🏠 카페 운영자 (CAFE_OWNER)

시작하기 — 회원가입 & 인증

카페 운영자는 휴대폰 인증이 필수입니다. 아래 순서대로 진행하세요.

1

앱 설치 및 회원가입

Android · iOS 앱을 설치하고 카페 운영자 역할로 가입합니다. 소셜 로그인 또는 이메일 가입 후 역할 선택 단계에서 카페 운영자를 선택하세요.

2

휴대폰 번호 인증

카페 운영자는 휴대폰 번호 인증이 필수입니다. 인증 완료 후 카페 등록 또는 운영자 신청 단계로 이동합니다.

3

카페 연결

기존 카페를 검색해 운영자 신청을 보내거나, 새 카페를 직접 등록 신청합니다. 관리자 승인 후 운영 권한이 부여됩니다.

💡 Tip. 가입 직후 연결된 카페가 없으면 카페관리 탭에 빈 상태 화면이 표시됩니다. 화면의 기존 카페 검색 또는 새 카페 등록 버튼으로 바로 진행할 수 있습니다.

카페 등록하기

기존 카페 운영자 신청과 신규 카페 등록, 두 가지 방법을 안내합니다.

🔍

방법 ① 기존 카페 운영자 신청

이미 콘카에 등록된 카페의 운영 권한을 신청합니다.

  • 카페관리 탭 → 기존 카페 검색
  • 카페명 · 지역 · 주소로 검색
  • 해당 카페 카드의 이 카페 운영자 신청 버튼 클릭
  • 신청 메시지 입력 & 운영 증빙 이미지 업로드 후 제출
  • 관리자 승인 후 카페관리 탭에 카페가 표시됨
✏️

방법 ② 신규 카페 등록 신청

콘카에 아직 없는 카페를 새로 등록합니다.

  • 카페관리 탭 → 새 카페 등록
  • 카페 이름 · 주소 · 소개 · 대표 이미지 입력
  • 지도에서 위치 핀 설정
  • 등록 신청 후 관리자 심사 → 승인 시 카페 공개
상태

신청 상태 확인

카페관리 탭 신청 상태 카드에서 현재 진행 상황을 확인할 수 있습니다.
승인 대기 관리자 검토 중   승인 완료 운영 권한 부여   반려 재신청 가능

카페 대시보드

카페관리 탭에서 운영 중인 카페를 선택하면 대시보드로 진입합니다.

📊 오늘의 현황

오늘 방문자 수, 체크인 수, 신규 리뷰 수, 평균 평점을 한눈에 확인합니다.

⚡ 빠른 이동

캐스트 관리 · 출근표 · 이벤트 · 카페 설정 · 홈 배너 관리 화면으로 바로 이동합니다.

🔗 외부 링크

SNS, 예약 페이지 등 외부 링크를 등록하면 대시보드 카드 목록으로 노출됩니다. 탭 시 앱 내 WebView로 열립니다.

💡 Tip. 여러 카페를 운영하는 경우 상단 카페 변경 드롭다운으로 운영 중인 카페를 전환할 수 있습니다. 운영 카페가 1개이면 탭 진입 시 대시보드로 바로 이동합니다.

캐스트 관리

소속 캐스트 프로필 등록 · 수정, 출근표 관리, 프로필 연결 요청 처리를 합니다.

①

새 캐스트 프로필 추가

대시보드 → 캐스트 관리 → 캐스트 추가 버튼을 누릅니다. 활동명, 컨셉 역할, 생일, 소개, 근무 요일을 입력하고 저장합니다. 프로필 이미지는 서버에 업로드됩니다.

②

출근표 관리

각 캐스트의 근무 요일을 castSchedules 기준으로 등록합니다. 홈 화면의 생일인 메이드 섹션과 탐색 탭 캐스트 카드에 자동 반영됩니다.

③

프로필 연결 요청 승인 / 반려

캐스트 계정이 본인 프로필 연결을 신청하면 캐스트 관리 섹션 상단에 요청 카드가 나타납니다. 신청자 활동명, 연결 대상 캐스트명, 신청 메시지를 확인 후 승인 또는 반려를 선택합니다.

⚠️ 프로필 연결 요청은 최신순으로 최대 3건까지 표시됩니다. 전체 보기를 누르면 모든 요청을 확인할 수 있습니다.

메뉴 · 굿즈 관리

대시보드 → 메뉴&굿즈 관리에서 판매 상품을 등록하고 관리합니다.

☕

메뉴 관리

  • 메뉴 탭에서 항목 추가 · 수정 · 삭제
  • 이름 · 가격 · 설명 · 카테고리 입력
  • 판매 상태: 판매 중 / 품절 토글
  • 삭제 시 확인 다이얼로그 후 최종 반영
🎁

굿즈 관리

  • 굿즈 탭에서 항목 추가 · 수정 · 삭제
  • 이름 · 가격 · 이미지 · 재고 수량 입력
  • 재고가 0이면 자동으로 품절 표시
  • 삭제 시 확인 다이얼로그 후 최종 반영
💡 Tip. 메뉴·굿즈 추가·수정·삭제 후 목록은 화면을 다시 켜지 않아도 실시간으로 갱신됩니다. 저장 후 바로 반영 여부를 확인하세요.

공지 · 이벤트 관리

대시보드 → 공지 및 이벤트 관리에서 팬에게 소식을 전달합니다.

📢

공지사항

  • 공지 탭 하단 시트 → 제목 · 내용 · 상단 고정 여부 입력
  • 고정 공지는 카페 상세 공지 탭 최상단에 표시
  • 목록 페이지 크기: 15건씩 표시
🎉

이벤트

  • 이벤트 탭 하단 시트 → 제목 · 내용 · 기간 · 대표 이미지 1장
  • 이벤트 기간 설정으로 시작일 · 종료일 지정
  • 홈 화면 배너와 연계 가능 (홈 배너 별도 등록)

홈 배너 관리

대시보드 → 홈 배너 관리에서 앱 홈 화면 상단 배너를 등록합니다.

배너 등록

배너 이미지 · 제목 · 서브 문구 · 연결 링크(카페 상세 / 이벤트 / 외부 URL) · 노출 기간을 입력합니다.

배너 상태

DRAFT 임시저장   SCHEDULED 노출 예약   ACTIVE 노출 중   종료 · 일시정지 가능

슬롯 제한

동시 활성 배너는 최대 5개입니다. 슬롯이 가득 찬 경우 예약 등록만 가능하며, 기존 배너 종료 후 자동 승격됩니다.(프리미엄 등록시 7개 까지 노출가능)

⚠️ 카페 운영자는 본인 운영 카페와 관련된 배너만 등록할 수 있습니다.
🎀 캐스트 (CAST)

시작하기 — 회원가입 & 소속 카페 선택

캐스트 계정으로 가입하고 소속 카페와 본인 프로필을 연결합니다.

1

회원가입 — 역할 선택

앱을 설치하고 회원가입 단계에서 캐스트를 선택합니다. 활동명 · 생일 · 소속 카페를 입력합니다. 소셜 로그인 또는 이메일 가입 모두 가능합니다.

2

소속 카페 선택

콘카에 등록된 카페를 검색해 소속 카페를 선택합니다. 선택한 카페 정보는 연결 대기 상태로 저장됩니다.

3

캐스트 프로필 연결 신청

가입 완료 후 팬관리 탭에서 기존 캐스트 프로필을 검색해 연결 신청을 보냅니다. 소속 카페 운영자가 승인하면 연결이 완료됩니다.

💡 Tip. 캐스트 계정은 회원가입 자체는 즉시 완료됩니다. 기존 캐스트 프로필과의 연결은 운영자 승인이 필요하며, 승인 전에도 팬관리 탭의 기본 기능을 이용할 수 있습니다.

캐스트 프로필 연결하기

팬관리 탭에서 본인 캐스트 프로필을 찾아 연결 요청을 보냅니다.

①

팬관리 → 캐스트 프로필 연결 섹션

하단 탭 팬관리로 이동합니다. 프로필 연결 섹션에서 소속 카페에 등록된 캐스트 목록을 확인합니다.

②

본인 프로필 선택 → 연결 요청 전송

목록에서 본인의 캐스트 프로필을 찾아 연결 요청을 보냅니다. 요청 후 승인 대기 상태로 표시됩니다. 재신청은 불가하며 운영자 처리를 기다립니다.

③

승인 완료 또는 반려

운영자가 승인하면 캐스트 프로필과 계정이 연결됩니다. 반려된 경우에는 반려 상태가 표시되며, 프로필 목록에서 다시 연결 신청이 가능합니다.

⚠️ 콘카에 본인 캐스트 프로필이 없는 경우, 운영자가 먼저 프로필을 등록해야 합니다. 소속 카페 운영자에게 프로필 등록을 요청하세요.

팬관리 탭 기능

캐스트 전용 탭으로, 팬과의 소통과 일정 관리를 지원합니다.

👤

내 프로필 요약

연결된 캐스트 프로필의 팔로워 수, 프로필 이미지, 소개 문구가 표시됩니다. 프로필 수정으로 이름 · 컨셉 역할 · 생일 · 소개 · 근무 요일을 업데이트할 수 있습니다.

📅

출근 일정 바로가기

근무 요일을 등록하면 카페 상세 화면의 오늘 출근 캐스트 섹션에 자동 반영됩니다. 일정 변경 시 프로필 수정에서 근무 요일을 업데이트하세요.

📣

팬 대상 공지 · 알림

팔로워에게 공지 메시지를 보낼 수 있습니다. 공지는 홈 화면 카페 공지 섹션에도 노출될 수 있습니다.

🔗

소속 카페 대시보드 바로가기

소속 카페의 정보를 확인하는 바로가기 링크입니다. 운영자 권한은 없으며 카페 정보 조회만 가능합니다.

자주 묻는 질문 (FAQ)

Q. 카페 운영자 신청 후 얼마나 기다려야 하나요?

관리자가 수동으로 검토하므로 처리 기간은 신청 상황에 따라 다릅니다. 카페관리 탭의 신청 상태 카드에서 현재 진행 상황을 확인할 수 있습니다.

Q. 카페 운영자 신청이 반려됐습니다. 어떻게 해야 하나요?

반려 상태가 표시되면 신청 카드에서 재신청 버튼이 활성화됩니다. 반려 사유를 확인하고 운영 증빙 이미지 등 필요한 정보를 보완해 다시 신청하세요.

Q. 캐스트 프로필 연결이 필요 없이 캐스트 기능을 사용할 수 있나요?

회원가입 자체는 프로필 연결 없이 완료됩니다. 단, 팔로워 수 표시, 팬 공지 등 일부 기능은 캐스트 프로필이 연결된 후에 완전하게 활성화됩니다.

Q. 메뉴를 추가했는데 카페 상세 화면에 바로 반영되지 않습니다.

메뉴·굿즈 변경은 저장 후 실시간으로 반영됩니다. 잠시 기다린 후 화면을 아래로 당겨 새로고침해 보세요. 반복적으로 발생하면 앱을 재시작해 주세요.

Q. 홈 배너 슬롯이 모두 찼을 때 새 배너를 어떻게 등록하나요?

활성 슬롯이 가득 찬 경우 즉시 게시는 불가하며 예약 등록만 가능합니다. 기존 활성 배너가 종료되면 예약된 배너가 순서대로 자동 활성화됩니다.

Q. 여러 카페를 운영하는데 탭 진입 시 어떤 카페가 표시되나요?

운영 카페가 2개 이상이면 진입 시 내 카페 목록이 먼저 표시됩니다. 카드를 탭해 원하는 카페의 대시보드로 이동하거나, 상단 드롭다운으로 카페를 전환할 수 있습니다.

Q. 이용 중 문제가 생기면 어디에 문의하나요?

앱 내 내 정보 → 설정 → 문의하기를 통해 문의를 남겨주세요. 또는 고객지원 페이지를 방문해 주세요.
